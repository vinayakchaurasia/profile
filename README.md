# Vinayak Chaurasia Portfolio

Static portfolio website for GitHub Pages.

## Edit content

Update [profile-data.js](./profile-data.js) to change:

- About
- Core expertise
- Skills
- Experience
- Projects
- Education
- Certifications

## Local preview

Open [index.html](./index.html) in a browser.

## GitHub Pages publish

1. Create a public GitHub repository named `profile`
2. Push this folder to the `main` branch
3. In GitHub go to **Settings -> Pages**
4. Under **Build and deployment**, choose:
   - **Source:** Deploy from a branch
   - **Branch:** `main`
   - **Folder:** `/ (root)`
5. Save and wait for deployment

Your site URL will be:

`https://vinayakchaurasia.github.io/profile/`
